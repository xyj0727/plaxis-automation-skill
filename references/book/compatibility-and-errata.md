## 已核实的公式疑误

教程 PDF 101–102 / 印刷 88–89 页的表 6-2、表 6-3，在扫描件中将剪切模量关系的分母印为 `1(1+ν')`。用于计算时采用各向同性线弹性关系：

```text
G = E / [2(1 + ν)]
K = E / [3(1 - 2ν)]
Eoed = E(1 - ν) / [(1 + ν)(1 - 2ν)]
```

校核依据：PLAXIS 3D 2024.1《Material Models Manual 3D》，2023-12-29 版本，PDF/印刷第 18 页 Eq. [31]；第 22 页 Eq. [54] 再次给出同一剪切模量关系。参数必须保持有效应力/总应力体系一致。输入辅助刚度或波速可能改变主模量，回读时应一起核对。

其它书页疑点在 `page-ledger.jsonl` 的 `uncertainties` 及各主题模块中保留。扫描不清、OCR 误识别与原书疑误是三类不同问题，不可混为已核实的勘误。

## 材料属性与 API 迁移

官方[材料属性变更表](https://bentleysystems.service-now.com/community?id=kb_article_view&sysparm_article=KB0108381)记录了多个版本间的属性重命名。不要把网页当前最新列自动映射到用户机器；先用对应版本 Objects reference 或对实际材料 `echo` 检查。界面强度的手动取值通常还受其确定方式控制，单独写入 `Rinter` 并不证明已启用手动模式。

官方 [2024.1 发布说明](https://bentleysystems.service-now.com/community?id=kb_article&sysparm_article=KB0107792)指出旧工程转换、重新计算以及部分单位情形重新剖分的要求。转换前保留整套原工程；不要把转换副本的存在等同于结果兼容。

连接基础见官方[Python wrapper 说明](https://bentleysystems.service-now.com/community?id=kb_article_view&sysparm_article=KB0108870)。Input 和 Output 分别连接；打开 Output 和结果提取采用脚本，并核对打开的工程与阶段。
