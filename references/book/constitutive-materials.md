# 本构、排水类型、界面与结构材料

来源：教程6.1、6.2、6.4–6.9节，印刷页79–115、129–142（PDF92–128、142–155）。本文件按物理含义重组书中参数、图表和操作经验。书中为2013时代软件；旧版可选类型、默认值和参数联动均需现版验证，不以“书中给过”代替项目参数确认。

检索词：LE、MC、HS、HSsmall、SS、SSC、JR、MCC、NGI-ADP、Hoek–Brown、UDSM、Undrained A/B/C、Rinter、OCR、POP、Rayleigh、Plate、Geogrid、Beam、Embedded、Anchor。

## 材料组与作用范围

材料分土/界面、梁、Embedded桩、板、格栅、锚六类；土/界面又分一般、参数、渗流、界面、初始条件五页。逐页核对，不能只读E、c、φ就宣称材料完整。[PDF92–94]

项目库保存本工程材料，全局库便于跨工程复制。必须先从全局复制到项目库，再赋给几何；全局示例材料不是现工程的默认材料。新建、编辑、复制、删除、SoilTest操作不同；单阶段变材通常先复制材料、改副本、再作阶段赋值，避免影响共享引用。[PDF92–94、154–155]

材料名、颜色和注释用于识别，但实际检查应保存材料对象ID、类型、参数及所赋对象。土层的材料共享于各钻孔同一层；阶段赋材可与初始几何赋材不同。

## 先选行为，再选模型

| 模型 | 主要用途与参数结构 | 不可推定的能力 |
|---|---|---|
| LE | E、ν；线性各向同性弹性，可表征高强结构/岩石的简化响应 | 不预测土塑性破坏、应力相关刚度或卸载硬化 |
| MC | E、ν、c、φ、ψ；常刚度理想弹塑性，适初步评估 | 一个E不能同时可靠代表初载、卸载和所有围压 |
| HS | E50ref、Eoedref、Eurref、m及强度；剪切和压缩硬化、应力相关刚度 | 不自动模拟软化、任意循环累积及液化 |
| HSsmall/HSS | HS加G0ref、γ0.7；小应变刚度退化与卸载历史 | 滞回不等于完整循环损伤、软化或液化模型 |
| SS | λ*、κ*等；正常固结软土主压缩 | 开挖卸载问题不能仅因是软土就优先使用 |
| SSC | SS类行为加μ*；次压缩/蠕变 | 时间单位及历时不正确时不能解释长期变形 |
| JR | 岩石各向异性弹性+1–3组弱面塑性 | 弱面方向错误会改变破坏机制 |
| MCC | λ、κ、M、e及历史；临界状态软黏土模型 | λ与SS的λ*不是相同输入，不可混用 |
| NGI-ADP | 主动/被动/直接剪切不排水强度各向异性及路径相关应变 | 不可只给一个su就声称已描述各向异性 |
| Hoek–Brown | E、ν、σci、mi、GSI、D等；岩体非线性强度 | 不能直接以任意土MC的c/φ替代 |
| UDSM | DLL声明的模型和参数 | 必须核DLL版本、参数单位、排水支持和单点行为 |

上述比较来自PDF95–96、103–113。模型复杂度高不等于证据更充分；缺关键参数时列缺项及来源候选，不能用默认值填齐后假称已确认。

## 排水类型与分析类型

| 类型 | 刚度/强度输入 | 孔压与强度解释 |
|---|---|---|
| Drained | 有效参数 | 不按不排水约束生成超孔压，适合对应长时/充分排水过程 |
| Undrained A | 有效刚度+有效强度 | su是模型沿有效应力路径算出的结果，须与实验检查；能产生孔压不代表孔压准确 |
| Undrained B | 有效刚度+输入su | su是输入；可给孔压，但可能偏差较大，固结后不能假定su自动增大 |
| Undrained C | 不排水总应力参数Eu、νu、su | 不区分有效应力与孔压，不输出所需孔压响应；不能据此解释排水固结机制 |
| Nonporous | 相应固体参数 | 无初始/超孔压，常用于实体结构；不是“土的k很小”的替代 |

书中排水类型主要作用于Plastic/Safety/Dynamic；Consolidation及完全耦合中的排水由k与水力边界控制，水可压缩性还受材料设置影响。现版须检查计算类型与排水字段实际组合；不要用Undrained选项替代渗透率、阶段时间和排水边界。[PDF96–98、126–128]

旧书的可选组合如下，作为迁移检查清单，不作当前枚举表：LE可Drained/A/C/Nonporous；MC可Drained/A/B/C/Nonporous；HS/HSS可Drained/A/B；SS/SSC/MCC主要Drained/A；JR/HB可Drained/Nonporous；UDSM见DLL支持。NGI-ADP节另列Drained/B/C，不能用6.2节对LE/MC的说明排除全部其他模型。[PDF101–113、127–128]

MC/HS/HSS采用B时，书中以su代替c，φ=ψ=0；C采用Eu、νu、su及φ=ψ=0。书中提醒HS/HSS采用B时失去应力相关刚度与压缩硬化，应按现版模型手册核验这种组合的后果。[PDF102–105、127]

νu接近0.5可表示近不可压缩，但不能直接取0.5导致刚度矩阵奇异。书示0.495–0.499属于经验范围，不是缺参时自动填值。有效ν′不等于νu。[PDF128]

## 一般属性、密度和孔隙比

γunsat是非饱和区域的实际总重度，不应无条件取干重度；水位上黏土可能因毛细作用接近饱和。γsat是饱和总重度，均为力/体积。书中的水位分区在完全耦合分析会随孔压和饱和状态变化，不能把全部阶段重度分区固定理解为初始水位。[PDF97]

孔隙比与孔隙率关系为 `e=n/(1-n)`。einit为初始值，体变会更新e；emin/emax可与HS/HSS剪胀截断联系，达到最大孔隙比后剪胀角可归零。它们不是可随意设大/设小的纯数值容差。[PDF98]

## 弹性、MC及深度梯度

各向同性弹性关系：

```text
G = E / [2(1+nu)]
Eoed = E(1-nu) / [(1+nu)(1-2nu)]
rho = gamma/g
Vs = sqrt(G/rho)
Vp = sqrt(Eoed/rho)
```

E、G、Eoed为应力单位，ν无量纲，Vs/Vp为长度/时间。改变替代模量或波速会联动E，不能把它们都当互相独立的输入。[PDF100–102]

**原书勘误**：PDF101/印刷88表6-2、PDF102/印刷89表6-3的G分母印成`1(1+ν)`。本次放大原扫描确认该字样；现装PLAXIS材料模型手册第18页式31、第22页式54给出`2(1+ν)`，故采用上式。此纠正不改变书中其他参数来源。

书中E与c随深度可设线性增量：

```text
z < zref: E(z)=Eref+(zref-z)*Einc
z >= zref: E(z)=Eref
z < zref: c(z)=cref+(zref-z)*cinc
z >= zref: c(z)=cref
```

Einc/cinc单位为应力/长度；z为高程，不能把正深度直接代进去而又取负z。至少核对zref处及其下一参考点的读回值。[PDF101、103，式6-4/6-5]

MC拉伸截断独立于剪切破坏，容许抗拉强度须明确；书中默认0仅为历史默认，不替代有胶结或岩体的物理依据。[PDF103]

## SS、SSC、MCC、JR、NGI-ADP与HB的额外输入

- **SS**：λ*修正压缩指数、κ*修正回弹指数；可用Cc/Cs/einit表达替代输入；c′/φ′/ψ、νur、K0nc、M、拉截断也要检查。[PDF107]
- **SSC**：再加μ*或Cα描述次压缩，参数无量纲但预测依赖时间单位、应力历史和历时；不可拿普通固结时间替代蠕变标定。[PDF108]
- **MCC**：λ、κ、ν、einit、临界状态线斜率M与K0nc。λ/κ与SS的带星号参数不要直接相等。书中M–K0nc长公式和底部误写SSC的提示存在阅读/排版风险，当前实现应依现版模型手册，不从低清式重建本构。[PDF110]
- **JR**：连续岩石E1/ν1、弱面方向弹性E2/G2/ν2；每组弱面ci/φi/ψi/抗拉强度、倾角和倾向；弱面数1–3。先画方向向量，再检查是否与实际地层/节理面一致。[PDF109]
- **NGI-ADP**：Gur/suA，三轴压缩/伸长/DSS破坏剪应变（书中按%输入），主动su参考值、参考深度和随深度增量，压缩/主动、被动/主动、DSS/主动强度比、τ0/suA、有效/不排水ν。表6-10的主动参考强度单位疑似多写`/m`；应力本身与应力梯度必须分别按现版字段核验。[PDF111–112]
- **HB**：E、ν、完整岩石单轴抗压强度σci、mi、GSI、扰动D，以及ψmax和控制剪胀退化的围压尺度σψ。σci/σψ为应力，其他除角度外无量纲。参考图中超大或零占位输入不是有效岩体参数。[PDF112]
- **UDSM**：选择DLL及其中模型后读取参数名称、单位与模型支持组合；保存DLL身份/版本和单点验证依据。高级不排水参数可涉及Skempton B、νu、Kwref/n，不得只因为界面可输入就自行指定物理值。[PDF113]

## Rayleigh阻尼

书中关系为：

```text
C = alpha*M + beta*K
xi(omega) = alpha/(2*omega) + beta*omega/2
omega = 2*pi*f
```

α单位1/时间，β单位时间；α主控低频，β主控高频。选择两目标频率和阻尼比可解两元线性系统：`alpha + beta*omega_i^2 = 2*xi_i*omega_i`。不需要抄写容易识别错误的长分式。[PDF98–100，式6-1至6-3]

书例f1=1.5 Hz、f2=8 Hz、两处ξ=0.08，给α约1.2698 s⁻¹、β约0.002681 s。它只演示双点拟合，目标频带外阻尼会更大，不能把该组数值用于所有地震/振动项目。塑性耗能、HSS滞回与额外粘性阻尼应同时审视，防止重复计入。[PDF99]

## 水力材料

渗流/固结需kx、ky、kz，量纲长度/时间；近不透水的多孔层也需明确k，Nonporous不是其替代。考虑非饱和过程还需饱和度–吸力和相对导水率关系。标准/Hypres/USDA/Staring预置精度有限，不能按中文土名对号入座。[PDF113–120]

自定义VG可输入Sres、Ssat及ga/gl/gn；样条模型输入压力/毛细水头、相对渗透性Kr、饱和度Sr；Saturated模型持续使用饱和性质。θr/θs是体积含水量，Sres/Ssat是饱和度，二者不可直接混填。[PDF119]

ψunsat用于限制高度非饱和范围内的Kr/S变化，使其保持下限；它不是新的真实土层厚度。书中的10⁴长度单位为几乎不截断的数值默认，不能未经检查当实测吸力范围。[PDF120]

考虑固结中的渗透率变化时，书中式6-6为 `log(k/k0)=Δe/ck`，以十进对数使用时 `k=k0*10^(Δe/ck)`；须具备einit、ck及适用模型说明。不启用变化时大ck近似常数。历史分类参数及所有表6-13至6-16数值见[hydraulic-presets.md](hydraulic-presets.md)，均为候选来源而非项目默认。

## 界面强度、刚度和厚度

界面通常以周围土参数和Rinter定义，但MCC界面直接给c′i/φ′i/ψi，UDSM还可能需Eoed,i等。因此不能对所有材料只设置一个Rinter后宣称界面完整。[PDF121、124]

`Rigid`对应Rinter=1及与土关联的强度，不等于无滑移tie或无限刚度；`Manual`显式输入Rinter；`Manual with residual strength`另给残余折减。书中“缺资料可假设2/3”的经验不能覆盖用户要求的缺参确认流程。[PDF121–123]

对书中常见关联界面，压应力取负时：

```text
c_i = Rinter*c_soil
tan(phi_i) = Rinter*tan(phi_soil)
Rinter < 1 时 psi_i=0；Rinter=1 时可继承psi_soil
|tau| <= -sigma_n'*tan(phi_i)+c_i
sigma_t,i = Rinter*sigma_t,soil
```

即折减的是tanφ，不是φ角度本身。弹性滑移/张开仍可能存在；达到强度后才转塑性相对位移。[PDF122–123，式6-9至6-12]

书中刚度关系：`Gi=Rinter²*Gsoil`、`νi=0.45`、`Eoed,i=2Gi(1-νi)/(1-2νi)`，`Ks=Gi/ti`、`Kn=Eoed,i/ti`。相对弹性位移为`Δus=τ/Ks`、`Δun=σn/Kn`。这是特定界面模型关系，Rinter既影响强度也影响刚度，不应通过调Rinter无依据地“修好收敛”。[PDF122]

**两种厚度不同**：虚拟厚度ti影响数值弹性刚度；实际剪切带厚度δinter用于例如HS界面孔隙比/剪胀截断，可能影响抗拔。后者常与粒径相关但需物理依据。任意降低虚拟厚度可能导致病态，任意提高又可能增大假弹性滑移。[PDF79、122、124]

考虑Gap closure时，张开后反向加载要先闭合才能恢复压接触；未考虑时可能立即产生接触应力。需与预期脱开/再接触过程一致。[PDF123]

人工延伸至结构趾部之外的界面用于消除角点锁定/振荡，应与真实接触面区分。书中建议独立Rinter=1材料，以免人为降低土强度。[PDF80、124]

残余强度达到峰值后软化，书中不建议在Safety强度折减计算使用降低残余强度；若确有需求须按现版求解机制论证。HB界面通过当前围压下的等效切线c/φ表达，但原书式6-15出现符号疑误，不能作为可执行公式照搬；应用现版材料模型实现并读回。[PDF123]

## K0、OCR与POP

`K0x=σxx′/σzz′`、`K0y=σyy′/σzz′`。正常固结的Jaky关系为`K0nc=1-sinφ′`，只在适用假定下采用；手动K0和自动K0应保留实际读回值。[PDF124]

用压应力大小表示，`OCR=σp/σv0′`，`POP=σp-σv0′`。固定OCR与固定POP在深度上给不同的历史状态，不能互换名称。高级模型的帽面初始位置由应力历史控制，必须同时核OCR/POP、K0nc与当前有效应力。[PDF125–126]

对无黏材料，书中提醒K0应避免超出 `(1-sinφ)/(1+sinφ) < K0 < (1+sinφ)/(1-sinφ)` 以免初始处于破坏。它不是所有岩土材料的通用数值输入范围。K0过大/小、初始应力平衡不成立，应查物理初始化，不把计算不收敛直接归为网格问题。[PDF125]

## 板材料

板d为等效厚度，普通实心平板可为实际厚；对特殊截面应以所需轴向和弯曲刚度等效，不能只用外轮廓厚度。单位面积自重为γd。板几何零厚且可能与土重叠，应按实际置换体积核对自重，不能无条件从所有板材料重度扣土重度。[PDF142–143]

正交各向异性需E1、E2、ν12、G12、G13、G23及局部轴。1/2在板面内、3为法向；各向同性时E2=E1、G=E/[2(1+ν)]。PDF63写轴2垂直面的句子与此处及图6-42矛盾，不沿用该句。书中剪切修正系数5/6及内力矩阵为理论说明，当前单元具体实现以现版手册为准。[PDF144–145]

局部内力N1/N2、Q12/Q13/Q23、M11/M22/M12与轴向对应，改变面局部轴可能改变分量名/符号而非物理合力。导出时保留坐标转换，不把不同朝向板的同名M直接叠加。[PDF145]

书中板默认零厚不提供实体端承；End bearing选项用等效弹性区模拟板趾承载，`Deq=sqrt(12EI/EA)`。该选项需项目物理依据及现版支持，不能为了改善沉降随意开启。[PDF144]

## 格栅材料

格栅有拉伸刚度，无抗压/弯曲；弹性或弹塑性类型要明确。`EA=F_per_width/(ΔL/L)`，单位力/长度；来自制造商曲线时需注明应变区间及长期/短期条件。各向异性需EA1/EA2/GA；书中各向同性EA2=EA1、GA=EA1/2。[PDF145–146]

书中将2D材料导入3D时给出`GA=min(EA1,EA2)/2`的历史转换规则；PDF146正文中“平面内/平面外”的解释带有轴对称/2D背景，不将它作为3D格栅轴2法向的依据。导入后读回两面内方向刚度、剪切刚度与真实局部坐标。[PDF146]

塑性时Np1/Np2是每单位宽最大拉力。材料强度在积分点控制，节点外推输出可能略超Np，不能仅看节点最大值就声称程序未执行强度上限；应核应力点、外推方式和局部轴。[PDF147]

## 梁与Embedded桩材料

梁需真实截面A、材料γ、E、I2/I3；线重γA，弯曲刚度EI2/EI3，惯性矩单位长度⁴。局部2/3方向决定强弱轴。零体积梁与土重叠时按实际置换检查净重；为减自重而改γ也会影响轴力解释。[PDF147–148]

Embedded预定义圆形、圆管、方形或自定义截面；输入E、γ、A、I2/I3与相关直径/壁厚。书中等效半径：

```text
Iavg=(I2+I3)/2
Req=max[sqrt(A/pi), sqrt(2*Iavg/A)]
```

Req控制桩周弹性区，截面几何不只影响EA/EI。其无体积/不考虑打桩效应的理想化须与安装方式相符。[PDF149–150]

轴向侧阻Tmax单位力/长度，端阻Fmax单位力；端阻只在向桩底压入时发挥。线性侧阻容量 `N=Fmax+L*(Ttop+Tbottom)/2`；分段线性侧阻为各段梯形积分 `N=Fmax+sum[0.5*(Li+1-Li)*(Ti+Ti+1)]`。表中L沿桩轴从头至底，不是斜桩的竖向深度。[PDF151–152]

土层相关侧阻由c/φ/Rinter及应力状态决定，并可设Tmax限幅；它与直接输入线性/多段最大阻力不同。至少记录所选模式、全部侧阻点、端阻、连接与实际桩长。轴向容量是部分模型输入，不能把达到输入上限宣称为独立预测的承载力。[PDF149、151–152]

## 锚材料与预应力

锚EA单位力，结合实际/等效长度得到EA/L轴向刚度；弹塑性需最大拉力/压力，残余模型还需残余拉力/压力。书中涉及按平面外间距折算的语句属于平面应变口径，三维单根锚不能照搬该除法。[PDF153]

书中残余锚达到峰值后立即降至残余并保持；停用再激活会视为新锚恢复初始强度。若要代表同一根已受损锚的重新受力，不能用这种操作无意“修复”材料。[PDF154]

预应力是施工阶段的Adjust prestress操作，不是材料组的固定物性。保存阶段、目标锚、预应力值、激活状态和后续是否调整；材料相同并不意味着各阶段预应力相同。[PDF154]

## 最小读回清单

每种材料读回模型、排水、单位、重度、主/替代刚度、强度、历史、水力、界面和高级设置；每个结构读回材料ID、截面、局部轴、连接、激活阶段。用SoilTest核材料点行为，再用与参数相关的小模型核建模/求解/提取流程；参数确认与流程验证必须区分。[PDF94、128–141、155]
