# 孔压、水力边界、固结与完全耦合

来源：《PLAXIS 3D基础教程》第7章，印刷153–162、168–169、175–183、189–190页（PDF166–175、181–182、188–196、202–203），并交叉参照第9章印刷230–232页。内容为书页原创归纳，未作当前软件实测。数字默认值均是书版说明，不自动转为新项目取值；名称、支持范围和单位需在当前版本中确认。

## 1. 先分清变量和正负号

PLAXIS书版压缩应力和水压力取负，吸力为正。以下关系适用于书中有效应力框架：

- `σ = σ′ + pactive I`；孔压只加到法向项，不改变剪应力。
- `pactive = Seff * pwater`。饱和时两者相同；非饱和时不能用PWater直接代替参与有效应力的PActive。
- `pwater = psteady + pexcess`；稳态分量与瞬时超孔压应分别输出。
- `h = z − pwater/γw`，水头单位为长度，γw是水重度。这里竖向坐标为z。
- 正PWater对应吸力；正PActive对应有效吸力。`有效吸力*tanφ`可表现为额外抗剪贡献，不等于新增真实黏聚力材料参数。

内部孔压与外部水荷载也不同。模型外部水位以及开挖后水体会在土边界形成水荷载；删除土单元不自动把水也删除。提取或计算平衡时，不能漏掉外水压力。

## 2. 选择哪一种计算与孔压生成方式

| 目标 | 合适的书中概念 | 必须明确 |
|---|---|---|
| 静水分布作为变形初始输入 | Phreatic / 潜水位 | 全局水位、各类组水力条件、吸力开关、外水荷载 |
| 稳定地下水流场 | Steady groundwater flow | 水头/流量/渗出边界、非零渗透性、非饱和关系 |
| 单独求随时间变化的水流 | Transient flow-only | 非零历时、时变边界、渗透性/储水及非饱和参数，不包含结构变形反馈 |
| 固定稳态基准下的超孔压发展消散 | Consolidation | 超孔压排水边界、加载历时/停止准则、渗透性 |
| 时变水边界与土变形同步演化 | Fully coupled flow-deformation | 总孔压边界、加载历时、饱和/非饱和材料、水流和力学条件同时核查 |
| 水力状态完全不变的后继变形阶段 | Use previous phase pressures | 先确认无影响水域的激活/冻结及边界变化 |

普通Plastic不模拟时间消散；输入非零TimeInterval并不会把它变成固结。其排水终态可以回答某些长期位移问题，但不能给出真实沉降时间曲线。书版Flow only在初始阶段设定后锁定后续分析类型，现版应核查支持关系。

传统固结主要对超孔压求解；Undrained C不提供相同的孔压耦合响应。完全耦合直接计算总水压力与位移，适于快速降水/库水骤降、部分排水开挖、波浪或非饱和边界变化。书中完全耦合的稳态分量基于阶段末水力边界另求，因此`pexcess=pwater−psteady`的参考并非当前时刻静水面；不能把正负超孔压仅按直觉解释。

## 3. 固结停止准则和时间步

按施工持续时间分析时，给定本阶段总历时，施工变化随该阶段推进；无新加载的保持固结阶段也可使用Staged construction。以最小孔压结束时，判据为全域最大超孔压绝对值低于指定应力阈值，所需时间由计算得出。以固结度U结束时，书中将其转成母阶段最大超孔压的剩余比例阈值：若U以百分数输入，概念上为`(1−U/100)*|pexcess,max,parent|`。这不是严格的“沉降已达到最终沉降U%”的同义词。

书中默认最小孔压1个应力单位、固结度90%仅为版本默认。不可把1误当总孔压，也不可把MPa工程中的1与kPa工程中的1当相同物理阈值。书页关于“固结度低于目标”及百分数公式存在文字歧义，见[版本与疑点](errors-version-notes.md)。

固结/完全耦合自动时间步根据迭代难度和非饱和状态变化调整。首时间步通常基于材料和几何的总体临界时间步；Retrieve得到建议值后，手动Apply改变实际设置。时间步并非越小越稳定：过小可能产生压力振荡/严重发散。应保存建议值、用户确认值与实际步长，不用随意缩步长替代参数或边界检查。书版固结/耦合不使用弧长控制，其未收敛不能直接当承载力破坏。

## 4. 水位对象及逐类组赋值

钻孔水头可以生成水位面：单钻孔为水平，多钻孔可形成非水平插值面。书中用户水位由零压点坐标与压力随深度变化定义。水位对象跨阶段共享，修改几何定义会影响所有引用它的阶段；要为某阶段改变水位，应复制水位并给该阶段引用，避免修改公共对象。

书版只允许水平用户水位绑定时间函数，钻孔水位和非水平水位有额外限制。`Create reached water level`保留母阶段末水位为常值；`...and continue`继承函数并添加已有累计时间偏移；前者“冻结期末状态”，后者“延续过程”。时变渗流边界也有对应的保持期末值/延续函数选择。

| 类组条件 | 用途与检查 |
|---|---|
| Global level | 引用本阶段全局水位生成该类组孔压；不意味着其它类组也是同一静水分布 |
| Custom level | 选择独立钻孔/用户水位；旧中文“自定义标准”是误译，不是材料标准 |
| Head | 快速指定水平零压参考高程zref |
| User-defined | 输入zref、pref及压力梯度，适用于线性非静水分布，注意压力负号 |
| Interpolate | 沿竖向在上层底与下层顶的孔压间线性插值，适合不同含水层之间隔水层；缺端值时书版使用全局水位 |
| Dry | 排除该类组初始和超孔压并禁止水流通过，类似非多孔水力处理；不自动调整邻层孔压 |

非水平水位下简单按各竖向水柱静水分布，可能不满足真正的渗流场；应根据问题选稳态/瞬态渗流。低渗透层并不等于Dry。干开挖需要显式定义开挖空间内水压力及降水边界，不能只deactivate土类组。

## 5. 开闭边界、渗出面与孔压预览

书版普通模型除顶面外默认闭合，顶面打开时倾角不超过45°的上表面也按顶边界处理；开挖露出的内部面通常成为打开边界。此规则必须读回当前模型，尤其斜面、挡墙及新开挖面。

Consolidation中的开闭控制超孔压能否消散；Flow和完全耦合的开闭控制水流进出并影响总孔压。Open不等于无条件零总孔压：全局水位以下通常为给定水头，以上为渗出面；显式面水力边界可覆盖这些隐式条件。机械固定与水力封闭是两套不同边界，不能互相推断。

正式计算前预览阶段水压力：检查激活土体内部PWater/PActive、潜水位、开挖区、外水荷载及边界零压位置；再读回每个阶段的全局水位和类组条件。预览只是输入场核对，不是已完成渗流或变形计算的充分证据。

书中“激活界面完全不透水、冻结界面完全透水”是旧版描述。现版界面机械激活与水力条件需分别查证；不可凭界面存在或Rinter值判断防渗。

## 6. 降雨与蒸发

Precipitation的q表示竖向回灌强度，物理单位为长度/时间，正值入渗、负值蒸发。先将mm/h、mm/day等换到项目长度/时间单位。斜坡法向通量为`q*cosα`，α为坡面与水平夹角，不要把同一竖向雨量重复按坡面实际面积施加。

`ψmax`、`ψmin`是相对边界高程的压力水头上、下限，单位长度。正入渗达到上限后切换为相应水头边界，表示积水/径流限制；负蒸发达到下限后由相应水头限制继续失水。书中0.1与−1是示例默认，不应直接成为实际地表积水或吸力参数。截图q单位和正文不一致，采用物理量及现版属性核验。

显式渗流面边界与降雨重叠时书版优先面边界，降雨会被忽略；因此应审查受雨表面集合而非只看全局Precipitation=True。瞬态/耦合可绑定Discharge function，检查函数起点、阶段累积偏移、结束值和雨后保持阶段，防止每阶段重复从零开始。

## 7. 吸力、空化与误差

Ignore suction主要截断正稳态孔压；并不普遍清除不排水卸载生成的正超孔压。未忽略吸力时，土水保持曲线决定有效饱和度及吸力参与强度的比例。空化截断限制水张力，与土体Tension cut-off不是同一功能；书版A/B可用，完全耦合的支持不同。开关及阈值必须有物理依据，不为提高收敛随意切换。

独立渗流有自己的容差、最大步数及超松弛；书中示例为0.005、1000、1.5。非饱和计算还检查局部封闭水相关误差，以及连续步饱和度/相对渗透性变化；全局误差很小仍可能局部失败。水力和力学的计算状态、单位、时间和实际边界应共同归档。
