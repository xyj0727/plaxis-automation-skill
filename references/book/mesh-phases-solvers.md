# 网格、施工阶段、求解与误差判断

来源：用户提供的《PLAXIS 3D基础教程》，第7章，印刷143–198页（PDF156–211）。本文件为逐页图文核读后的原创操作归纳。书中界面主要对应旧版；以下API映射均需在目标版本中用命令帮助、对象属性和读回确认，本文没有执行本机PLAXIS试验。水力内容另见[水力与固结](groundwater-consolidation.md)，旧版及疑点见[版本说明](errors-version-notes.md)。

## 1. 网格策略与网格审计（印刷143–146、203页）

几何模型、有限元网格、施工阶段是不同层次。先把土层、结构、接触、荷载及边界定义成几何，再生成共同拓扑网格，最后按施工阶段控制参与计算的对象。阶段描述期末目标；非线性求解器用多个荷载步实现状态变化，不应把一个施工阶段当成一个求解步。

书中基本单元为10节点二次四面体土单元；梁为3节点线，板和格栅为6节点面，界面为12节点配对面。节点/应力点的身份关系必须保留，特别是界面的同坐标双节点。网格图中界面可被人为拉开显示，显示间距不是物理厚度或开缝。

书式7-1给出目标尺寸：

`Le = (re / 20) * sqrt((xmax-xmin)^2 + (ymax-ymin)^2 + (zmax-zmin)^2)`。

表7-1的旧版等级“很粗、粗、中等、细、很细”对应`re=2、1.5、1、0.7、0.5`。因此模型域或地上结构高度变化时，相同等级也会改变绝对网格尺寸。比较工况须同时记录包围盒、目标尺寸、局部系数、实际单元/节点数及质量；不能把`re`直接当现版`mesh`命令的参数。实际目标尺寸从网格日志或Output一般项目信息核对。

局部系数相对于全局尺寸。旧版普通对象默认1，结构/荷载0.5，允许范围0.0625–8；大于1表示粗化。体、面、线、点均可影响局部网格，不要只检查结构面而遗漏荷载线和交线。应力集中、接触端部、曲率、较大位移梯度和高水力梯度处优先细化。书中折线角容差30°、曲面角容差15°是旧版默认，减小会增加几何离散精度与单元数量。

粗网格用于检查模型域、边界和预期变形位置；参数确认后再用有明确关联的小模型或易错工况验证流程、收敛和提取。网格收敛应针对目标响应，位移看似稳定不代表极限荷载、结构弯矩或界面峰值已稳定。不得用试算替代缺失材料/界面参数的来源确认。质量指标须写明定义，书中的内外接球质量与当前网格器的其他指标不可直接比较。

## 2. 阶段树及修改传播（印刷146–150、159–160、184–196页）

初始阶段自动存在。添加阶段时必须明确母阶段；不同加载方案可以共享同一个已平衡母阶段。Safety或推至破坏的分支是评价支路，继续施工应从其之前的正常施工阶段另建子阶段。插入/删除阶段会重接母链，必须重新审查下游初始条件与施工定义。

每阶段保存以下最小清单：系统标识与用户名称、母阶段、计算类型、加载类型、孔压生成方式、历时、激活/冻结集合、逐对象材料与荷载、位移约束、接触与水力状态、清零/更新网格开关、求解器/线程、迭代参数、存储步策略、原生结果状态和最后日志。阶段表格视图便于比较，脚本交付应形成等价的逐阶段读回表。

几何默认属性与阶段显式覆盖不同。更改几何模式默认值不一定覆盖阶段中已重定义的值；更改母阶段也不保证已存在子阶段自动更新。书中`Regenerate`按属性继承关系传播，而不是无条件整树复制。对自动化而言，完成修改后逐阶段读回比假定继承可靠。几何变化后需要重新划分网格、重选曲线点、核对拓扑命名和阶段设置；旧结果不能继续标作新几何结果。

激活与可见性分开：隐藏对象仍可参与计算；冻结对象不因显示出来就恢复作用。冻结土单元不计其自重、刚度与强度，应力清零，新增边界变成自由边界；水压力另行处理。再次激活的土单元从零应力开始，但刚度/强度在该阶段初始就存在；自重及状态改变形成不平衡力，由荷载步逐渐平衡。新填筑层可带无应力预变形衔接既有网格，这影响后处理位移口径。

改材可以模拟改良或材料随阶段变化，但重度、强度、刚度变化都是新的平衡变化；不能当成只换标签。新建荷载和指定位移往往有默认非零分量，必须显式设置所需分量并读回。体积应变需启用Apply，正表示膨胀、负表示收缩；其方向和大小属于物理输入，不能用来补偿模型误差。

锚预应力的`Adjust prestress`通常只在张拉阶段启用；后阶段关闭调整，已形成轴力作为初始内力继续发展。把预应力数值设成零会强制卸载，不能用于表达“以后不再调张拉力”。

## 3. 初始应力与变形计算类型（印刷150–159页）

### K0与重力初始化

水平地表、水平土层及平行水位下可用K0；明显倾斜地形、非水平重度分布或不相容地层应采用能平衡该几何的重力加载方案。初始应力必须先计算、查看有效应力和塑性状态，再继续正式施工。

`K0x=σ′xx/σ′zz`、`K0y=σ′yy/σ′zz`。正常固结土常见Jaky估算`K0nc=1−sinφ`，但不是所有土的无条件取值。高级模型还受OCR、POP及卸载泊松比影响；书式7-4为：

`K0 = K0nc*OCR − νur/(1−νur)*(OCR−1) + (K0nc−νur/(1−νur))*POP/|σ′zz,0|`。

这需要与具体本构和输入定义相容。无黏性土的局部不屈服筛查区间为`(1−sinφ)/(1+sinφ) < K0 < (1+sinφ)/(1−sinφ)`，满足该范围仍不保证整个应力场平衡。不得仅为减少塑性点就擅自把已确认K0调向1。

对于MC弹性一维压缩重力加载，`K0=ν/(1−ν)`。若目标K0大于1，不能通过非法泊松比硬凑，应依据应力历史或合适初始化方法。HS等高级模型的初始化关系不同。重力初始化中的长期自重不宜产生不合理超孔压；书中对A/B材料使用忽略不排水行为，并在后续阶段清零人工初始化位移、保留应力。

K0轻微残差可用不改变几何、荷载和水力条件的Plastic零加载阶段平衡。严重不平衡不能靠无限零加载修复，应重新检查初始应力方法。HS正常固结帽盖/硬化点不等同于MC破坏点。

### Plastic、Safety与Dynamic

Plastic通常为小变形弹塑性计算，时间间隔不会自行产生孔压消散；SSC蠕变等时间相关材料另论。完全排水Plastic可估长期终态，但不提供固结过程。忽略A/B不排水行为不作用于C，也不会清除以前已有超孔压。

Safety对土与界面的`c、tanφ、su`按共同总强度折减乘子处理：`ΣMsf = tanφ_input/tanφ_reduced = c_input/c_reduced = su_input/su_reduced`。剪胀角不应超过已折减摩擦角。板/锚等结构强度不随此乘子自动折减。必须检查Msf-位移平台和破坏机制完整性；完成最大步数只是数值过程完成，不是安全系数已稳定的充分条件。书版高级模型在该阶段采用起始应力对应刚度且不继续原硬化过程；MCC、UDSM与Hoek-Brown具有特殊处理，见版本说明，不能照搬未经当前手册确认的折减规则。

Safety有两个不同目标（7.4.4–7.4.5）：`Target ΣMsf`用于取得指定折减水平的结果，书版先识别完整破坏，再重算接近目标总乘子的步骤；`Incremental multipliers`中的`Msf`只是首步折减增量，后续由自动步长控制。书版首步0.1、默认100步及上限1000步都是历史设置。按步数完成的绿色状态意味着步数预算执行完毕；若Msf尚无平台或机制不完整，必须明确“安全系数未确认”，不可把任意末值报成安全系数。

Dynamic用于应力波/振动，动力基值与已激活时程乘子共同构成输入；移除先前静荷载可激发自由振动。稳态孔压来自母阶段，超孔压产生能力取决于本构。采用黏性边界时要核查边界位置、入射方向、C1法向与C2切向系数，不能仅凭“viscous”标签声明无反射。

### 更新网格与重置

更新网格是Updated Lagrangian大变形分析，包含几何刚度、有限转动应力率与坐标更新，不是后处理显示变形网格。先用常规模型核查，再据真实比例变形和必要对照判断几何效应。书版不支持完全耦合/Dynamic与更新网格组合；一旦进入更新网格链，不能任意切回小变形或再次清零位移；从普通计算转入时需按版本规则清零初始化位移。Safety只继承母阶段结束几何，不逐Safety步更新。

清零位移保留应力，但HSS会重置应变历史，重新动员小应变刚度；重置状态变量还会改变预固结/硬化历史，不能当成无影响的显示操作。更新网格并不意味着水力边界和应力点孔压同步重构，分布荷载的跟随方式也需明确。

## 4. 结构连接与模型边界（印刷185–190页）

结构共节点默认传递其共享自由度。书中定制板板线铰、板梁点铰以及膨胀连接依赖界面双节点提供附加自由度；缺少界面节点会产生无效连接。板作reference，梁不能作reference；板板选择顺序影响reference/custom，必须读回而非按视觉猜。定制连接默认释放转动而约束平移；释放平移才形成相应滑移/膨胀缝。两部件均激活连接才起作用，书版连接属性跨阶段共享。

一般土边界为侧面法向位移固定、底部三向固定、顶部自由。非轴向侧边和延伸至边界的板梁可能带额外位移/转动约束。自定义面指定位移可覆盖默认约束，尤其顶面与侧面共边须检查是否丢失水平约束，必要时用明确的线约束表达真实物理条件。应读回对象约束并检查反力/刚体运动，不能仅报告“默认边界”。

## 5. 求解控制的含义（印刷159–177页）

| 控制项 | 使用含义与核验 |
|---|---|
| ΣMstage | 本阶段从母状态向目标状态推进的比例，通常0→1；达到1可提前结束，不能称“物理极限状态” |
| MaxSteps | 本阶段求解预算；不等于MaxStepsStored，也不等于各步迭代上限 |
| MaxStepsStored | 结果保留策略；最后步及中间抽样保存，实际可用数据需逐步检查，不能许诺全历史 |
| MaxLoadFractionPerStep | 单步阶段加载比例上限f，至少约ceil(1/f)步完成目标，实际可更多；不保证等步长 |
| 最大/期望迭代次数 | 最大值限制单步成本；期望范围驱动自动荷载步放大/缩小 |
| ToleratedError | 平衡/本构误差容许值；更小不自动修复错误模型，更大不自动使错误结果有效 |
| 最大卸载步 | 连续卸载达到阈值可触发破坏判别；机制切换中的暂时卸载需要曲线证据 |
| 弧长 | 可跟踪极限附近荷载下降；Safety/荷载控制重要，位移控制是否关闭应按已验证方案 |
| 超松弛/线搜索 | 固定/自适应地缩放迭代修正，提高效率的效果依问题，不是物理参数 |
| 渐进误差降低 | 书版从10倍容差开始向期末目标收紧，会影响中间求解路径；报告不能说全过程相同容差 |
| Solver/cores | Picos迭代、Pardiso直接、Classic单核的资源取舍；实际求解器枚举、线程与内存读回确认 |

书中6–15次期望迭代、0.5最大加载比例、0.01力学容差、1.2超松弛等是旧版标准设置，不是新项目的默认物理/数值方案。外推利用前一成功步作新步初猜，但仍需平衡迭代。对参数缺口按用户要求指出并确认，不用大规模试算“选出”参数。

自动荷载步的书版逻辑为：低于期望最少迭代次数则尝试扩大步长，高于期望最多次数且未平衡则缩小步长，区间内接受并沿用前步增量作为下一初猜；示例放大/缩小倍数为2。终极水平法以达到目标状态结束，不能把名称中的“终极”理解为极限承载力；加载步数法则追踪指定步数，包括机制已形成后的过程。对前者，“目标未达到”至少区分土体破坏、加载算法无法推进、预算不足、用户取消与输入/数值错误；对后者，达到步数不替代破坏机制判断。

`ΣMweight`是材料自重总乘子，1表示输入重度完全施加。书中举例包括忽略材料自重的单元试验、先提高重力再卸回1以形成高级模型的超固结历史，以及离心模型的重力缩尺；这些均为专门的模型设定，不能因初始化困难而自行改动。采用重力预压时要核查卸载后真实应力、预固结状态及新增塑性，不能只改最终乘子。

动力真实积分步长为`dt=DynamicTimeInterval/(MaxSteps*Substeps)`，时间单位为秒。常规阶段时间按项目单位，不能混用。Newmark书中符号为`α、β`，稳定性条件`β≥0.5`、`α≥0.25*(0.5+β)^2`，平均加速度示例`α=.25、β=.5`；与常用文献的β/γ命名不同，映射前核查。更多阻尼参数不是更准确的自动保证。

书版动力积分在阶段内采用固定临界步长，由材料波速、最小单元尺寸及输入时程精度共同估算，再分配最大步数与子步数。Retrieve/Apply关系、实际步数及子步结果保存范围应分别核查。动力累计时间只在动力阶段增加，普通阶段不使其归零；常规总时间包含动力阶段经过的物理时间。连续地震记录、停振和后固结阶段须分别核对这两套时钟，避免重复加载同一时段。

## 6. 执行、监控与结果是否可用（印刷191–198页）

计算前检查标记集合，避免重算未授权正式结果。停止、暂停、完成与失败的状态分别记录。运行中区分最后成功步的乘子/反力与当前尝试步误差；组装、预处理、矩阵分解、求解、写盘都会占时，单次CPU/文件时间戳不变不足以判定卡死。只操作本任务明确拥有的进程，不运行遗留示例中按进程名批量结束全部会话的命令。

失败按证据分类：目标未达但步预算耗尽；加载过程失效；局部接触/塑性点误差；约束不足导致奇异矩阵；不适合时间步的固结发散；输入/网格数值错误；文件缺失；RAM不足。不要统称为土体破坏，也不要无差别增大步数或降低容差要求。

书式7-15将节点残差按激活荷载与CSP加权未激活荷载归一；CSP接近0表示数值柔化。局部误差另比较平衡应力与本构应力差，并按抗剪强度标度归一，界面同时涉及法向和剪向误差。书版终止还要求土体和界面不准确塑性点分别不超过`3+塑性点数/10`。这说明GlobalError低于容差并不足以判整个步合格；现版应保存其原生全部判据，不用书版公式覆盖求解器。

交付时分别给出计算状态、实际Reached值、目标位移/荷载是否达到、局部与整体精度、实际保存步、物理响应判断。正常收敛的小模型证明流程可用；不能自动证明正式网格独立、参数合理或极限承载力已确定。

Reached字段也有分析类型语义：Pmax在固结中对应超孔压，在单独渗流中对应稳态孔压，在完全耦合中对应激活孔压；同名字段不能跨类型直接拼表。Reached total force指非零指定位移节点上的方向反力合量，不是全部固定边界的反力总和。Reached ΣMstage、ΣMweight、ΣMsf及总时间分别与原目标对照；CSP为数值相对刚度指标，接近0仅是机制诊断线索，不单独充当极限荷载判据。
