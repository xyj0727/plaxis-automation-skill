# 输出变量、位置、符号与结构内力

来源：《PLAXIS 3D基础教程》第9章印刷224–236页（PDF237–249），交叉参照第7章孔压定义及误差章节。这里解释结果的物理含义；现版ResultTypes名称、node/stresspoint支持范围与局部轴方向必须查询并读回，本文没有把书中菜单等同于可运行API。

## 1. 结果请求必须包含的身份

每一份数组或极值至少记录工程、阶段ID、原生步ID/时间、实体或材料子域、结果名、单位、数据位置(node/stresspoint)、全局/局部方向，以及是否总量/阶段量/步增量。结构面上的土侧和结构侧同坐标节点不是同一个结果对象；不能仅按XYZ去重后混合。

单元关联图将界面双节点拉开显示用于表达连接。两个土体之间有界面时通常通过界面配对连接而非共享节点；板两侧都建界面时板土也不共节点。检查连接是否成立要用实际节点实体和位移/内力，不以图上相接认定。

## 2. 位移、速度、加速度与应变（9.2.1–9.2.14）

| 结果族 | 含义 | 常见误读 |
|---|---|---|
| Deformed mesh | 按显示倍率画出的变形网格 | 自动放大形状被当成真实尺度；显示变形被当成启用了更新网格 |
| Total displacement | 当前步累计位移，受中间清零设置影响 | 用Utot模代替加载方向Ux，或将参考点位移当基础顶位移 |
| Phase displacement | 当前阶段从母阶段起始状态到当前步的位移变化 | 与“上一个列表阶段”作差，忽略真实母链 |
| Incremental displacement | 当前计算步的位移增量 | 当成当前整个阶段位移；不同自动步长下直接比较幅值 |
| Sum phase displacements | 去除新激活单元预变形后累积阶段变形的口径 | 与Total混画；中间清零后可能比Total大，并非算错 |
| Velocity / acceleration | 动力响应，分别为长度/秒和长度/秒² | 与静力步增量相混；把g倍数当m/s² |
| Acceleration in g | 加速度相对重力加速度的无量纲比 | 漏掉乘除g的单位换算 |
| Cartesian strain | 三正应变与三工程剪应变，分别有总/阶段/步增量 | 工程剪应变γij与张量分量εij相差2 |
| Principal/volumetric/deviatoric strain | 由应变张量得到的标量或方向 | 不核查压缩符号与主值排序，或把应变云图称为塑性点历史 |

分层填筑时，新层会有无应力预变形与已有沉降面衔接。图9-2说明普通总位移与阶段位移求和的施工解释不同：后者可避免把施工前尚不存在那一层的沉降计入其自身变形，截面可能在层间出现台阶。采用哪个口径由监测定义和施工标高决定，不能为了曲线好看切换。

小变形体积应变`εv=εxx+εyy+εzz`。书式9-1偏应变定义为：

`γs = sqrt((2/3) * [(εxx−εv/3)^2 + (εyy−εv/3)^2 + (εzz−εv/3)^2 + 0.5*(γxy^2+γyz^2+γzx^2)])`。

书式9-2为`e=e0+(1+e0)*εv`。使用这些式子必须确认应变符号、工程剪应变口径、应变测度和几何框架；不能把有限变形主伸长/对数应变直接代入小应变公式。书中更新网格体积公式和主应变提示存在适用范围/符号疑点，见[版本说明](errors-version-notes.md)。

## 3. 应力、主值和强度动员（9.3.1–9.3.4）

压缩为负。总应力与有效应力关系为`σ=σ′+pactive I`，总/有效剪分量相同，偏应力与主应力差也不因各向同性孔压平移而改变。书中主应力按`σ1≤σ2≤σ3`排列，因此σ1是压缩最大（代数最小）的主应力，不能按正压惯例排序后仍沿用原标签。

`τmob=(σ′3−σ′1)/2`为最大剪应力，即最大Mohr圆半径。书称“动剪切强度”的该变量表示当前动员剪应力，不是材料在任意路径下的独立极限强度。

MC相对剪应力：

`τmax = −(σ′1+σ′3)/2 * sinφ + c*cosφ`

`τrel = τmob/τmax`。

其含义是固定Mohr圆圆心、扩大半径到破坏包络时，当前半径占极限半径比例。它不是塑性累计量，也不是塑性区面积；达到或接近1不证明该点以前始终屈服。小分母、张拉截断、本构不适用和节点外推都可能影响解读，应优先读原生应力点与对应材料状态。

Hoek-Brown使用自身非线性包络：书式9-5至9-7以`fbar(σ′3)=σci*(mb*(-σ′3)/σci+s)^a`描述主应力差极限，`τmax=fbar/2`，`τrel=|σ′1−σ′3|/fbar`。不要把MC的c/φ包络公式用于未等效化的Hoek-Brown材料。

非多孔实体材料应力可能默认隐藏，需启用显示并按材料子域提取。土场数组与实体结构数组长度不同，不能截断、填零或按最近点把它们混合。

## 4. 状态变量按本构读取（9.3.5）

| 变量 | 适用解释 |
|---|---|
| 实际渗透性 | 饱和渗透系数×当前相对渗透系数，后者来自SWCC/渗流关系与饱和度 |
| HSS应变历史、Gs、G/Gur | 表示小应变历史及刚度退化；其他本构不能用缺失字段当0 |
| 等效各向同性应力peq | 当前应力状态对应同形硬化面的等向轴交点；各本构定义不同 |
| 前期固结压力pp | 当前步以前达到的最大等效各向同性水平，属于历史变量 |
| 各向同性OCR | pp/peq，不等于所有工程情境中的竖向OCR |
| HS/HSS硬化量γp | 当前实际硬化状态，不能用总剪应变替代 |
| 当前Eur | 应力相关模型在当前步起始应力下的卸载/重加载刚度 |
| 当前E | LE/MC中用于本步的刚度；可按深度增长，但这些模型本身不因此成为应力相关刚度模型 |
| 当前c | 反映材料及深度增长设置的实际黏聚力，需与所选阶段材料一致 |
| UDSM状态量 | 按该用户模型专用说明定义，不沿用其它模型字段含义 |

书式9-8（HS/HSS）与式9-9（SS/SSC/MCC）对peq的构造不同。可用原生peq/pp/OCR检验应力历史，而不从屏幕OCR公式自行实现新的本构算法；若需要离线重算，回到对应版本材料模型手册核实符号、帽盖参数、黏聚偏移和压力正负。书中MCC的黏聚参数为0，不能从其他本构复制c。

## 5. 孔压与渗流输出（9.3.6、9.3.10–9.3.11）

孔压的完整定义见[水力模块](groundwater-consolidation.md)。至少区分水头、PWater、PActive、PSteady、PExcess、阶段孔压变化、阶段截至当前步的超孔压最大/最小历史值、吸力、有效吸力。孔压标量没有主方向，图中沿坐标轴显示只是可视化编码，不是渗流方向。流向应使用实际通量/水力梯度结果。

即使Ignore suction打开，不排水卸载仍可能出现正超孔压。完全耦合的PExcess是与期末边界稳态场之差，不能当当前水位下的瞬时静水差。井结果表可查位置、流量与最小水头；排水线表可查位置、总流量和设定水头，避免把单位长度流量与总流量混用。

## 6. 塑性点、历史及精度（9.3.7）

书中屈服点、拉伸截断点、帽盖点、剪切硬化点及帽盖+硬化组合以不同符号显示。帽盖点表示到达相应预固结屈服面，不必然意味着工程破坏；HS/HSS硬化点与MC屈服含义不同。弹性点显示和只显示不准确点是独立筛选。

不准确塑性点表示局部数值误差超过限值；不要将其误命名成新的物理机制。当前塑性状态与整个历史曾经塑性是两种输出，必须分开。不可凭书中颜色直接猜现版PlasticPoint数值枚举，应查询原生版本表。

塑性带触及人为远场边界提示计算域需要复核；对称面、真实支承面不属于同一种远场截断。应结合位移、应变、牵引、状态和边界敏感性判断，不只看云图颜色面积。

## 7. 结构与界面（9.3.8–9.3.9、9.4.1–9.4.7）

先读取每个构件或单元的真实局部坐标，再解释内力。曲面分片、几何重建和斜梁/斜桩可能改变轴向；“局部1沿构件”之外的自动轴规则不能直接代替读回。

| 类型 | 结果及单位 | 方向/限制 |
|---|---|---|
| 梁 | N、Q12、Q13为力；M2、M3为力×长度 | 局部1轴向，2/3横向；拉N正压负，M2/M3绕相应轴 |
| 板 | 膜力/剪力为力/长度，弯扭矩为力×长度/长度 | 1/2在面内，3法向；M11对应绕2弯曲，M22对应绕1，M12扭矩 |
| 格栅 | N1、N2为力/长度 | 只承拉，不能把压缩状态当可承压板 |
| Embedded桩 | 梁式内力；Tskin、T2、T3为力/桩长；Ffoot为力 | 侧阻/端阻受输入极限约束，横向相互作用的书版控制来自周土塑性，不能误用轴向极限 |
| 锚 | 轴力为力，另有锚定杆旋角/等效长度等 | 标明当前值还是跨连续阶段最大/最小历史值 |
| 界面 | 法向有效/总应力、两剪应力、孔压等为应力 | 压法向负；两节点相对位移分别反映滑移/张开，单位长度 |

板/梁变形可取全局或局部、总/阶段/增量，转角另有字段。界面相对位移是节点对之差，需明确正负侧；共同平移不是滑移。强度动员用`τrel=sqrt(τ1²+τ2²)/τmax`，其中τmax依据当前有效法向应力和界面强度准则。法向总应力与有效应力只在验证孔压为零等适用条件下才可替代。

面单元内力是沿单位宽度的合量，不能将局部峰值直接当总反力。若要力/力矩平衡，需原生法向与切向牵引、坐标和正确面积/曲面积分，并与相同阶段步的原生反力比较。该积分方法不是本书本段已验证内容，应按现有技能的原生结果审计流程实施。
