# SoilTest与有证据的参数检验

来源：教程6.3节，印刷页115–129（PDF128–142）。这是单材料点验证和参数校准流程，不是用有限元试算猜缺失物性值的授权。缺参数仍应向用户说明并取得试验或文献依据。

## 试验功能的边界

SoilTest基于单应力点积分，检验所选本构和参数在给定应力路径下的响应，不需建立完整三维网格。它可以帮助发现单位、排水解释、应力历史和参数组错误；通过不等于工程模型通过网格、边界或施工验证。[PDF128–130]

材料参数与试验配置分开管理。将项目材料复制到试验，明确试验初始条件，计算并比对，再在有据确认后复制校准参数回新的材料组。不要直接覆盖共享材料后才发现其他阶段一起改变。[PDF129–130]

## 五种试验

| 试验 | 需要设定 | 能检验什么 |
|---|---|---|
| 三轴 Triaxial | 排水/不排水、压缩/伸长、等向/K0固结、围压、最大轴应变、步数、时间、前期应力 | E50、强度、体变、孔压与应力路径 |
| 侧限压缩 Oedometer | 初始/前期竖应力；各段竖应力增量、历时、步数 | Eoed、加载/卸载差异、压缩与回弹 |
| CRS | 初始/前期应力；各段竖应变增量、历时、步数 | 给定应变率路径下应力与时间效应 |
| DSS | 排水/不排水、等向/K0、初始竖应力、最大剪应变、历时、步数 | 简单剪切强度、剪切刚度、各向异性响应 |
| General | 初始应力状态；逐分量应力或应变控制及每段增量、历时、步数 | 自定义加载、卸载、循环路径 |

三轴围压输入以绝对值定义。在K0固结三轴条件，初始水平应力为围压，初始竖应力由围压/K0确定。DSS中等向固结水平应力等于竖向，K0固结水平应力为K0乘竖向。[PDF131–133]

书中三轴/DSS的“排水/不排水”试验选项可独立于材料库中排水类型；因此必须同时记录试验选项和材料排水类型，不能仅保存一者。SoilTest时间对时间相关本构有意义，不等于模拟实体试样的排水路径和孔压扩散。[PDF131–132]

高级模型还应输入竖向前期固结应力、初始相对剪应力动员比。HS/HSS的动员比从0（等向）到1（破坏状态）描述初始剪切硬化；未经依据不把界面示例默认值当项目实值。[PDF131–133]

负应力/应变增量表示压缩，正增量表示卸载或拉伸；零增量可用于保持段。分阶段时必须标注每段的“增量”与目标总量，避免把阶段末总应变重复作为每段增量。[PDF132–133]

## 数据导入与结果读取

文本曲线为两列，导入前指定分隔符、起始行、每列的物理量和基本单位。条件不相同时创建新的Custom试验，先设置排水、围压、路径等，再挂接对应曲线。`.vlt`可同时保留试验条件与数据；加载既有文件不能省略条件检查。[PDF136–139]

结果支持曲线与数据表，点击曲线点可显示局部切线与从原点得到的割线。轴常有反向显示，不能靠向左/向右判压缩或拉伸。对刚度，应注明切线/割线、应变区间、参考围压和加载/卸载路径。[PDF133–134]

与实测至少比较完整的相关响应，而非只拟合一个峰值：例如三轴q–εa、体变–εa、孔压–εa或有效应力路径。选择范围应与工程应变及应力水平对应。

## 参数优化

1. 只选择当前试验可识别的参数，并给有物理或试验依据的上下界。
2. 先检查原参数模拟与实测的差异，确认不是单位、路径或历史状态错误。
3. 三轴起段可先约束刚度，后段约束强度；加载与卸载可分组约束E50/Eoed和Eur。
4. 用Shift/Ctrl选连续区间或离散点，清楚记录拟合范围；不要任意删掉不利点以改善表观吻合。
5. 多阶段Oedometer/CRS/General优化一次针对单阶段，加载、卸载分别处理。
6. 读最优值、参数边界和敏感度。最优贴边可能说明范围不足；低敏感度可能说明该试验无法识别此参数。
7. 比较“目标数据”“优化后模拟”“原参数参考模拟”三组曲线，再用未参与拟合的条件检验。[PDF134–141]

粗/中/精搜索及相对误差控制数值搜索精度，不增加试验本身的信息。选过多相互耦合参数会得到多解或不稳定识别；软件返回一组最优值不代表唯一参数组。[PDF140]

书中工具不能直接把p–q破坏包络当普通响应曲线自动拟合，也不能一键拟合多段加载卸载。室内最优参数未必适合现场不同应力路径/应变幅值，工程迁移仍需独立验证。[PDF141]

## 应保存的最小记录

保存材料模型及版本、完整参数与单位、试验配置、原始实验曲线、拟合所选区间、优化上下界、固定参数、拟合前后曲线、敏感度、留出验证条件和参数修改理由。将“原材料”“拟合候选”“已确认参数”分开命名；试验验证不通过时先查物理假定，不通过大范围无依据搜参掩盖问题。
