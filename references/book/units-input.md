# 单位、项目文件与 Input 操作语义

来源范围：教程第1–3章，印刷页3–30（PDF16–43），并参考前言与功能概述。该书对应 PLAXIS 3D 2013 时代；这里提取操作语义和检查方法，菜单名及旧版许可标签不能替代当前版本的 API 探测。

## 选择分析与工作阶段

Input 建立几何、材料、网格、施工阶段并执行计算；Output 查看场量、剖面、结构结果与监测曲线。需要模拟三维空间作用的基础、掌子面、支护或局部结构时，应先核对二维简化是否改变荷载传递和破坏形态，不能因为软件支持三维就省略物理模型判断。[PDF14–16]

书中分析覆盖塑性、安全、固结、稳态/瞬态地下水、完全流固耦合和动力。分析类型不同，需要的时间参数、渗透参数及初始状态不同。不要将“排水类型”“地下水条件”和“计算类型”当同一个开关。[PDF14–16、96–98、126–128]

## 单位与符号

在定义几何之前确定长度、力、时间三个基本单位。书中示例通常为 m、kN、day；这只是书的口径，项目须采用确认的单位。

| 量 | m/kN/day 制下单位 | 关键检查 |
|---|---|---|
| 坐标、位移、水头、厚度 | m | 输入毫米前转换；水头是长度，不是压力 |
| 点力、锚轴向刚度 EA、桩端力 | kN | 不能与每单位宽度量混用 |
| 线荷载、桩单位长度侧阻 | kN/m | 积分后才是总力 |
| 面荷载、应力、E、G、c、su | kN/m² = kPa | MPa 值要乘1000 |
| 重度 γ | kN/m³ | 不是质量密度；ρ=γ/g 必须用相容单位 |
| 渗透系数 k | m/day | m/s 转为 m/day 乘86400 |
| 摩擦角、剪胀角、界面初相位 | 度 | API若使用弧度需显式转换 |
| 频率 f | Hz | 动力记录时间常为秒，不能因为项目时间day就直接混入 |

基本换算包括 1 m=1000 mm、1 kN=1000 N、1 day=86400 s、1 min=1/1440 day、1 h=1/24 day。英制项目另应明确 in/ft/yd、lbf/kip 的实际换算，不依赖文件名或界面语言判断单位。[PDF17–18，表2-1/2-2]

**中途更换基本单位存在不完全自动转换风险。** 书中明确：材料数据等部分值会转换，但几何、荷载、指定变位、水位以及程序外数据不能假定全部转换。已有项目换单位时，逐项核对原值、目标值和读回值，再重算；优先从开始就固定单位。[PDF18、21–22]

书中张量约定为压应力和压力孔压负、拉应力正。荷载方向按全局或局部坐标分量判断；不能因为“压力”一词就统一给所有字段加负号。水力曲线中的压力水头/吸力符号与应力输出的孔压符号还可能采用不同表示，需查看字段定义。[PDF18、49、120]

## 项目文件与可重现备份

一个原生项目由 `.p3d` 主文件及同名 `.p3dat` 数据目录共同组成。复制、移动、备份、交付时保持两者完整并处于同一父目录；单独复制 `.p3d` 不能代表完整工程。[PDF19]

书中打包工具可选择：

- 网格是否纳入。
- 全部、手动或含依赖链的阶段。
- 全部计算步、每阶段末步或手动选定结果。
- 快/高压缩与分卷大小。

因此“成功打包”不保证保留了全部曲线所需中间步。按交付目的核对实际选项，记录保留的阶段/步和缺少的历史；用于重现的包应保留所需依赖前序。[PDF22–24，表3-2]

新项目属性至少核对名称、说明、单位、重力方向及大小、水重度、平面边界。`设为默认` 只保存界面默认配置，不证明这些数值适用于后续工程。[PDF20–22]

## 五种模式与作用范围

| 模式 | 书中用途 | 常见误读 |
|---|---|---|
| Soil | 轮廓、钻孔、地层、初始水位与土材料 | Structures模式不能代替钻孔编辑 |
| Structures | 点线面体、结构、荷载、位移、水力几何特性 | 赋属性和重新创建几何不同，重建易重叠 |
| Mesh | 离散化、局部加密、网格及曲线点 | 改几何后旧网格和点映射不再可靠 |
| Water levels | 用户水位、相关阶段水条件 | 新水位不代表全部阶段已使用 |
| Staged construction | 激活/钝化、材料变更、荷载与计算阶段 | 创建对象不等于该阶段激活 |

前两种是几何模式，后三种是计算模式。书中的计算模式不能新增几何或新的几何特性，可调整已有特性的值。当前版本即便允许更多操作，也必须重新检查其网格和阶段影响。[PDF25–30]

浏览器应分别理解：模型浏览器列全部对象，选择浏览器只列选中对象的共同信息，阶段浏览器显示继承关系、执行状态和类型。多个对象的共同字段不等于每个对象的全部配置。[PDF39–43]

材料、动力乘子和渗流函数属于共享定义；改其内容可能影响所有引用。若只需某一阶段或某一部件改变材料行为，先复制材料成为新实体，再明确赋给目标，而非直接修改共享材料。[PDF40、92–94]

## 显示与物理状态必须分清

- 旋转/平移相机仅改变视图，旋转/移动对象才改变坐标。
- 透明、线框、隐藏是可见性；激活、冻结/钝化决定计算参与。隐藏对象仍可能承载。
- 正投影便于比较几何尺寸；透视有近大远小，不用透视截图测实际宽度。
- 局部坐标1/2/3与全局x/y/z不是同一组；书中显示颜色红/绿/蓝仅辅助辨识，最终应读向量。
- Ctrl逐个多选，框选方向可能区分全包/相交；命令执行前核对最终对象集。[PDF31–35]

三维鼠标绘图用工作面限制：默认在xy平面，Shift改变垂向；也可固定某一坐标或仅沿该轴运动。自动化应直接使用确认的数值坐标，并通过几何回读检查，避免把鼠标投影位置当空间坐标。[PDF34–36]

## 命令与索引

书中命令包含全局命令和针对命名对象的目标命令；参数有对象引用、字符串、整数、实数及枚举。字符串加引号，小数点用英文点。命令有别名和多种签名，必须选与参数类型匹配的签名，不能凭某个GUI标签拼出命令。[PDF36–38]

书中单下划线前缀通常与普通命令同义，双下划线命令可能用于调试或内部自动化；不移除未知内部前缀后盲目执行。`commands`/帮助参考可用于检查当前命令签名，但历史书中的签名不代表现版验证。[PDF37–38]

列表索引从0开始，负数从末尾引用；列表顺序可随创建/分割/合并改变。尤其结构特性的序号与赋值顺序未必一致。复用脚本优先保存对象引用，并按几何位置、对象类型和标识读回，避免用 `[-1]` 或第N项长期绑定同一物理部件。[PDF38]

界面操作生成命令历史；会话进程反馈和项目模型历史的范围不同。无错误弹窗、命令已发送或对象名称出现都不是成功建模证明，应读取命令响应、对象属性和阶段配置。[PDF25、36]
