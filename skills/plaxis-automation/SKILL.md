# PLAXIS 3D 自动化与教程知识

这是插件的加载入口。既有完整技能正文、工具脚本和新增知识库保留在插件根目录；以下相对路径均以本文件所在目录为基准，运行脚本前解析为绝对路径，不依赖用户当前工作目录。

1. 先读[版本与勘误](../../references/book/compatibility-and-errata.md)，区分旧正文、2013教程、对应版本文档和已实测行为。旧示例不能覆盖后续有明确范围的修正。
2. 依据任务查[教程知识索引](../../references/book/index.md)，只读相关主题；需要连接、完整脚本模式或历史故障经验时，查阅[原有完整技能正文](../../SKILL.md)的相应章节。
3. 建模前采用[参数与脚本核查流程](../../references/book/automation-review-workflow.md)。缺少依据的物理参数请用户提供或确认；不使用例题或默认值填补。先写完整脚本再运行，构建后回读几何、材料、边界、网格和阶段。全部工况参数确认后先验证关联小模型收敛，再展开全部正式工况脚本。
4. 脚本打开 Output 并提取实际保存的阶段/步。记录对象、数据位置、坐标系、单位、符号、计算状态和证据范围；数值终止、位移极值和教学截图均不能独立证明极限承载力。

使用[离线检索脚本](../../scripts/book_lookup.py)按关键词检索逐页笔记与主题正文，或用 `--page 101 --json` 查询 PDF 页。参数表须结合表头单位及上下文读取。原书、完整OCR和扫描图由用户本地保存，仓库仅提供提炼知识与页码定位。

[历史工具包](../../plaxis_toolkit.py)保留了原实现。运行前核查当前版本、目标路径、默认参数、超时、覆盖行为和异常处理；不要仅因文件可导入就直接覆盖用户打开的工程。仅关闭本任务拥有的进程，连接凭据从运行环境临时取得，不写入公开文件。
